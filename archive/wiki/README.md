# NumericalMOOC wiki archive

This directory is a self-contained archival export of the GitHub wiki that accompanied the legacy NumericalMOOC course repository. It preserves context that is not fully represented by the notebooks: the course philosophy, intended learning experience, original module descriptions, connected-course collaboration, learner and instructor expectations, enrollment and badge history, readings, and technical notes.

This material describes the historical course. It is not a supported setup guide for a current Python environment or the planned new edition.

## Export normalizations

The prose is preserved without copyediting. The readable snapshot differs from the source checkout only in these mechanical ways:

- filenames were normalized to lowercase, portable names; in particular, the colon in the JSAnimation page name was removed;
- CRLF line endings were normalized to LF;
- links among wiki pages were changed to relative links;
- notebook links on the home page were changed from the old HTTP nbviewer service to relative paths in this repository, with the adjacent link description adjusted accordingly;
- the externally hosted course banner was copied into `assets/` and referenced locally with descriptive alternative text.

External links and historical claims were not silently updated. Some services, software, affiliations, and communication channels named in the pages are obsolete.
